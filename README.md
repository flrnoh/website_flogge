# website_flogge

Persönliche Autorenwebsite — gebaut mit [Astro](https://astro.build).

## Setup

```bash
npm install
npm run dev
```

Öffne `http://localhost:4321` im Browser.

## Build

```bash
npm run build
```

Output landet in `dist/`.

## Design

Konzept: **Signal & Stille** — Teal für Technologie, Gold für Reflexion.
